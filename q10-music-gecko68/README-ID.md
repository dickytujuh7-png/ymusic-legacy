# Q10 Music — GeckoView 68

Aplikasi musik online khusus BlackBerry Q10 / BB10 Android Runtime.

- Mesin: GeckoView 68 ARMv7
- Minimum Android API 18, target API 18
- Situs musik: YouTube Music (music.youtube.com)
- Pencarian lagu/artis melalui YouTube Music
- Antarmuka native sederhana yang disesuaikan untuk layar Q10
- APK debug dibangun melalui GitHub Actions

## Catatan penting
Ini adalah aplikasi khusus YouTube Music yang membungkus situs resminya di GeckoView 68, bukan klien YouTube Music native. Fitur dan pemutaran audio bergantung pada kompatibilitas situs YouTube Music dengan mesin Gecko 68. Versi ini belum menjamin mode audio-only, pemutaran latar belakang, login, atau semua fitur situs. Pengujian akhir wajib dilakukan pada BlackBerry Q10.
