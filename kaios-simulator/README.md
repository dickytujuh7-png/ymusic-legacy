# KaiOS Simulator

An Android-based KaiOS-inspired interface simulator. This is a simulation, not the KaiOS operating system or a firmware port.

## Build

Open this folder in Android Studio, or use the repository GitHub Actions workflow to build a debug APK. Requirements: JDK 17 and Android SDK 35.

## Included in v0.1.0

- KaiOS-inspired home screen and app launcher
- Phone, Contacts, Messages, Browser, Gallery, Music, Clock and Settings demo screens
- KaiStore-style web catalog shortcut
- Responsive layout for Android phones

The simulator does not provide cellular calling/SMS, KaiOS app compatibility, or a real KaiStore installation.
